# Contactless Doorbell System

## Description

Arduino-based contactless doorbell that detects a person using an ultrasonic sensor and automatically activates a buzzer within 120 cm.

## Components Used

* Arduino UNO
* HC-SR04 Ultrasonic Sensor
* Buzzer
* Breadboard
* Jumper Wires

## Working

The ultrasonic sensor detects the distance of a person. When the person comes within 120 cm, Arduino activates the buzzer automatically.

## Pin Connections

| Component | Arduino Pin |
| --------- | ----------- |
| TRIG      | 9           |
| ECHO      | 10          |
| Buzzer    | 8           |

## Software

* Arduino IDE
* Arduino C/C++

## Applications

* Homes
* Offices
* Hospitals
* Smart buildings

## Result

The system successfully detects a person without physical contact and activates the doorbell automatically.
